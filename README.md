# 🧮 Scientific Calculator (Tkinter)

This is a **Scientific Calculator** built with Python and Tkinter.  
It supports **basic arithmetic operations** (add, subtract, multiply, divide) as well as **scientific functions** such as sine, cosine, tangent, logarithms, factorial, square root, powers, and constants (`π`, `e`).  

---

## 📋 Requirements
Make sure you have the following installed:
- Python 3.8 or above  
- Tkinter (comes pre-installed with Python on most systems)  

Check Python version:


---

## ▶️ How to Run

Download or clone this repository.
Save the calculator code into a file named: calculator.py
Open a terminal (or command prompt) in the project folder.
Run the program: python calculator.py

---

## 🎛 Features

- Normal Mode (basic calculator)

- Scientific Mode (advanced functions: sin, cos, tan, ln, lg, π, e, factorial, powers)

- Switch Mode: Toggle between normal and scientific layouts.

- Ans Functionality: Recall the last calculated answer.

---

## ❗ Troubleshooting

- If Tkinter is not installed: pip install tk

- On Linux, if you see No module named tkinter: sudo apt-get install python3-tk
